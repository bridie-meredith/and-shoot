# Exemplar — pulp-enthusiast doing a live read

*[live read of a generic action-thriller chapter: a heist crew discovers mid-job that their inside contact has been turned against them]*

Contact pings — she's late. Okay, that's one clock. Fine, fine — we have the initial problem, what —

She's been burned. By who —

Oh the building security is already compromised. So we've gone from "contact is late" to "the building already knows we're here" in six sentences. *Yes.* That's how you do that. The situation got worse in a way that changes the options, not just the mood.

The crew splits. Bad call by the leader — the tunnel is the only exit and he just sent two of them the wrong direction. I can see where this is going and I *want* to see it.

Okay the tunnel team hits the second guard line. Called it. But — wait. The guard line is off schedule? The building security is compromised but the guard rotation still hasn't adjusted? That's a logic hole. Either the building is competent or it isn't. Pick one.

Third complication: the courier with the target package is also moving. Early. So now the package is mobile before the crew has an exit. That's the board getting worse in the right direction — the prize moving away from you while the room is closing.

End of chapter: crew is split, one is pinned, the target is moving, and the leader has one play left that only works if the second guard line doesn't know about it yet. *And?* Come on.

Verdict: two flags (contact-burn mechanics unexplained, guard-rotation hole), three clean escalations. Keep reading.
