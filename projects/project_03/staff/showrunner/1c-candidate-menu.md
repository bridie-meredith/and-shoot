## SECTION 1 — PERSONAS: PROTAGONIST

**taylor-hebert**
- `card-status`: exists at `cards/personas/taylor-hebert.card.md`
- `canon-status`: canon (Worm)
- `quality`: full
- **Fit note:** The library card is calibrated for Earth-Bet / parahuman Worm context. The voice, fences, and vibe seeds are all correct for this project — she carries Gold Morning weight, tactical cognition, and the escalation-reflex. The fauna-control mechanics replace bug-control for this project (same power-shape, different substrate). **A project-scope variant card must be authored** at activation to:
  1. Hard-replace the bug-control stat block with Westeros-fauna control (insects, rats, ravens, no higher cognition)
  2. Add the physical cost mechanic (headaches, nosebleeds, blackout on overuse)
  3. Set age to 11 at episode 1 opening
  4. Set entry point to: orphan ward, small sept, Harrenhal shadow, 120 AC
  5. Remove Earth-Bet-specific relationships (Danny, Emma, Undersiders) from active relationships; retain as `memory burden / pre-Westeros context`
  6. Add the three opening pressures (impressment census, dying septon, castellan's men) to default-stance context
- The base card's voice, vibe seeds, action costs, and escalation structure all transfer cleanly. Do not re-author from scratch — variant is the correct path.
