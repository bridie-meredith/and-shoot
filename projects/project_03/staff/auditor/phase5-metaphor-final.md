## TASK 1 — Per-fire mechanic verdict

### @73 — Seam 1 defense review (AP4 domain-vs-structural)

**Question:** Does the rubric's AP4 gate operate at domain level (vehicle domain differs = clear) or at structural level (recognition-of-prior-acquaintance applied to threshold + body = same structure = fault)?

**Adjudication:**

The Phase 4 editor's reading is correct. The rubric §Anti-patterns reads AP4 as: "Metaphor that doubles a **figure** the memory-flag callback already carries." The operative word is "figure." In rhetorical terms, a figure is a specific vehicle-and-tenor pairing — not a logical structure that can be abstracted across vehicles. If AP4 operated at the structural level, it would bar all memory-callback metaphors from the facet, because the callback register is by definition a recognition-of-prior-acquaintance structure. The rubric explicitly lists the callback register as one of two licensed functional registers; a structural-level AP4 reading is internally inconsistent with that licensing.

The rubric's own example of an AP4 violation is: "Memory @33 'a closed-door-over-a-failing-tutor is not the first such door her body has stood at' already deploys the comparative shape; metaphor restating 'this door is another in the series' is the same figure twice." The example specifies: same domain (door), same comparison (series-member), same frame. That is a domain-level specification, not a structural-level one.

The Phase 3 seam's harder reading is noted: it is a genuine attack. But the rubric's language does not support it, and adopting it would make the callback register practically unlicensable.

**Verdict: Seam 1 defense HOLDS. @73 AP4: CLEAR.**
