# active-project — Gael Targaryen (cultivation-reincarnation comedy)

**THE LIVE ACTIVE PROJECT** (promoted 2026-06-14 from the `and-experiment` bones-first
prototype — it graduated; the completed Taylor project was archived to
`projects/taylor-westeros-good-intentions/`). Originally scaffolded by hand using
`/and-project` as the structural model, then developed bones-first (narrate/derive the
spine + outline, then reverse-build the apparatus).

**Project:** a cultivation-reincarnation comedy in pre-Dance Westeros — a dragonless,
setting-blind Targaryen princess who grinds dragon-adjacent matter into immortality
reagents and accidentally builds a trade empire, until she escapes south. One cohesive
3-book series (span A — the escape); the Dance is parked for a later installment. Full
bible: `active-project/design/run-01/{idea-board,constraints,treatment,book-outlines}.md`;
canonical build target: `active-project/intake/spine.md` (narrative) +
`active-project/design/run-04/series-outline.md` (tokenized; check-threads PASS).

## Layout
- `intake/spine.md` — the narrative source of truth (+ dated FOLDED changelog tail).
- `design/run-04/` — the canonical tokenized layer (series-outline + thread-config +
  family-tree + book-iii-rework). `scripts/check-threads.py` validates it. run-01..03 +
  `convergence/` retained as provenance.
- `staff/showrunner/memory.md` — project state (cross-session).
- `audience/` — bound trio: youjo-senki-reader, danmachi-reader, literary-snob.
- `warehouse/` — cards (personas, locations, props, conditions). `actors/` — provisioned
  cast working memory. `theater/ draft/` — pipeline state, populated as we build.
