# idea inbox — run-02

The front door for plot-revision notes. **Dump freely — messy, fragmentary, contradictory is fine.**
Coherence happens downstream (triage → ledger → thread audit), not here.

How it flows: you drop a note under "Raw" → I triage it (sort to chapters/entities, flag
contradictions + gaps, ask only what blocks) and read it back → on your confirm it's slotted into
`book-i-state-ledger.md`, the downstream state is recomputed, threads are checked, and the note is
moved to "Processed" with a one-line outcome + a pointer to the ledger change-log entry.

Format is loose. A note can be a chapter tag + a sentence, a paragraph of vibes, a "what if X",
or a list of disconnected fragments. Tag a chapter (e.g. `I.3`) if you know it; if not, leave it
untagged and I'll place it.
