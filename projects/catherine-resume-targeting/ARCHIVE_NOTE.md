# Archive — Catherine Olver Resume-Targeting Project

Archived 2026-05-22. Complete preservation copy of the `resume-targeting/` working project: a career-pivot analysis for Catherine Olver, EdD (special-education specialist moving into AI/education-adjacent work).

## Contents

| Path | What it is |
|------|------------|
| `Catherine_Career_Pivot_Master_Report.md` / `.docx` | The master deliverable — full consolidated analysis: opportunity landscape, per-position persona screening, next-steps, projected resumes, cross-role synthesis, recommended sequencing. |
| `Catherine_Opportunity_Report.md` | The opportunity landscape (8 roles, comp, fit matrix, weak spots, sequenced next steps). |
| `INDEX.md` | Role → screener-persona map. |
| `personas/` | The 19 screener persona cards (gatekeepers, 8 roles). |
| `resumes/` | Resume variants, v1 (`.docx`). |
| `resumes-v2/` | Resume variants, revised after critic review (`.md` + `.docx` + `.changelog.md`). |
| `reviews/`, `reviews-v2/` | Critic feedback per round, per resume variant. |
| `forks/role-NN-*/` | Per-position fork outputs: `persona-analysis.md`, `next-steps.md`, and the projected resume (`.md` + `.docx`) — the resume rewritten as if the 1-3 month next-steps were completed. |
| `staff/` | `RESUME_MD_FORMAT.md` (format contract), `md_to_docx.py` (resume converter), `md_to_docx_doc.py` (report converter). |

## Related, kept outside this archive (live repo libraries)

- `staff/screener-personas/` — reusable preservation copy of the 19 screener personas, indexed for future resume-targeting runs.
- `design/resume-targeting-method.md` — the process spec describing the end-to-end method used here, for re-running on a different candidate.
