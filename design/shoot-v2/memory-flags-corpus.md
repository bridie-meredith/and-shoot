## Notes on the corpus' Phase 1 use

Phase 1's naive baseline writer is rubric-blind. Expected naive failure modes (predicted; verified at end of Phase 1):

1. **No-monument fires** — naive author fires on charged beats (peaks, transitions) without monument-trigger discipline. Density-on-flat contamination on peak-aligned axis (the inverse of memory-flags' inverted-tens-density rule).
2. **Monument-leak** — naive author names monuments directly in description field. Hard-fence violations expected at high rate.
3. **Stage-named cue** — *she remembers ...* / *the memory rises ...* — naive author labels rather than producing the cue.
4. **Spineless fires** — naive author fires on beats where narrator-interest is silent (the locked NI file's silence is the spine constraint; a rubric-blind author won't know to consult it).
5. **Single-register file** — naive author over-fires Earth-Bet (the more accessible register; the variant card is denser) and under-fires Westerosi-monument clamp.
6. **Peak-density-on-tens-3** — naive author concentrates fires on @24/@38/@39/@64 because those are the dramatic peaks. The inverted-tens-density rule is counter-intuitive without the rubric.

Baseline accept rate (V2 strict) expected: very low (~5–15% range), comparable to state-updates' 6.7% baseline given the licensing-layer constraint adds further filter pressure.

V1 lenient accept rate expected: ~50–70% (form is easy to satisfy; the substantive failures are at the licensing / hard-fence / discipline level which V1 does not check).
