## Baseline strategy

No prior narrator-interest file exists. Per the tensometer pattern: synthesize a contaminated naive baseline by dispatching a rubric-blind dialogue-writer-fork to author entries from the proto-line file alone, with only the persona card and a one-paragraph "what is narrator-interest" frame. This produces the failure modes the rubric must catch (author-voice intrusion, density-on-flat, summary-of-the-beat, generic curiosity). Phase 1 V1 reviews the baseline lenient; Phase 1 V2 reviews it strict under the locked rubric.

## Expected fire count for s01e01 (under locked rubric)

12–19 entries on 77 beats (15–25% band). Tensometer fires non-1 on 16 beats (12 twos + 4 threes); not all of those fire in narrator-interest, and a handful of behavior-pack triggers on tens=1 beats (passive fauna establishment at episode open, refusal-to-look at @33 door-stays-shut, foreknowledge-clamp candidates if the dictation at @48 evokes any monument-register) earn fires off-curve.

## Stratified sample target

Phase 2 writer-fork should produce entries spanning (a) tens=3 peaks, (b) tens=2 transitions, (c) tens=1 behavior-pack-trigger fires (1–3 expected), (d) tens=1 ambient refusals (the silence-is-default cases). Phase 1 baseline does not need stratification — it should be authored naively, end-to-end, so the failure-mode taxonomy emerges naturally.

## Audience competence configuration

- **Mechanic auditor:** form, perceptual access, earning, anti-pattern check, curve-shape, cross-facet contract pre-ship.
- **Dialect audience:** voice fidelity only. Worm-canon-pedant primary (calibrated to base card and Westeros variant), dark-fantasy-reader and pulp-enthusiast secondary (catch generic-narrator vs genre-specific perception).
- **Verdict combination:** independent gates. Both must pass for ACCEPT. Either reject = revise. They cannot substitute.
