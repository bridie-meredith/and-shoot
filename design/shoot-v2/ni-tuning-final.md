## Rubric carry-back validation

Phase 3 seams file surfaced 3 rubric carry-back candidates. Audience adjudicates each:

**1. AP7 same-channel-different-content vs same-registration — scope of "same registration."**
The seams file asked: does AP7 fire on "same channel with different content" (column vs ledger angle) or only on "same registration" (identical construction)? Post-defense resolution: narrator:7 and narrator:22 were both revised, so the ap-002 violation is closed without a ruling on this ambiguity. The current rubric text does not make this distinction explicitly.

**2. Inferring another actor's cost-calculation: POV-licensed cost-tracking or omniscient intrusion?**

Carry-back: the rubric should add a sentence under §form distinguishing cost-tracking-from-observable-behavior (licensed) from interior-attribution (prohibited).

**3. Trailing-fragment discipline: syntactic-final-word vs semantic-load-position.**
The seams file asked whether the rubric's trailing-fragment requirement applies to the syntactic-final word or to the load-bearing semantic position.
