# Phase 4 Defense / Revise — Memory-Flags (post-mid-Phase-4 nudge)

The user's mid-Phase-4 guidance reshaped the rubric:

1. **Apply flags sparingly** — sparsity floor revised from 5–12% to **1–5%**.
2. **Max 1 per scene** — hard cap; doubled-register exemplars on a single beat are forbidden.
3. **Meaningful to both narrator and audience** — fires must land where both interior and audience register the beat as load-bearing. Interior-only foreknowledge fires (Westerosi monuments invisible to non-fluent readers) fail this gate by default.
4. **At a moment of realization, grim humor, social commentary, painting characterization** — the four functional-register jobs a fire serves.
5. **Several justifications or deny** — multi-justification gate; default to silence.

These supersede the Phase 2 / Phase 3 defaults. The Phase 2 8-entry shape (post-add) is reduced to 3 entries.
