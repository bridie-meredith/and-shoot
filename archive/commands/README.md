# Archived commands

Slash commands shelved out of `.claude/commands/` so the harness no longer surfaces them. Files preserved here (with full git history) for reference and potential reactivation.

## Contents

- `and-shoot.md` — full episode shoot orchestrator. Phase 0 archive, Phase A bullet plan, Phase B line-by-line shoot via coach + impersonator + audience review, Phase C mark `shot`.
- `and-wrap.md` — post-shoot manuscript finalizer. Dramatist scene boundaries, audience flag pass, fixer routing, editor polish to `active-project/polish/<slug>.md`.

## Why shelved

Shelved 2026-05-06. Review of `active-project/theater/s01e01-archive/show.md` showed the impersonator stage failing to render character voice — Taylor in particular reads as competent Westerosi prose without her interiority, and audience flags rewrite most of the first ~50 lines. Planning is judged solid; the failure is downstream.

The shoot phase is being redesigned rather than patched. Working thesis: move authoring effort earlier (tighter SVO proto-lines, multi-pass review) and split it by concern (action vs. dialogue vs. facets, each citable, stitched at the end).

## Where the redesign lives

`design/shoot-v2/`

## Reactivation

`git mv archive/commands/and-shoot.md .claude/commands/and-shoot.md` (and same for and-wrap) restores them. Do not reactivate without a decision recorded in `design/shoot-v2/`.
