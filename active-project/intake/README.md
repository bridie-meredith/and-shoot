# intake/ — outline re-baseline scaffold

The front door for a **tentative outline** that should **adapt or remove the existing planning**
(bigger than a chapter note). Designed to be picked up cold by a fresh session.

**Start here:** `INTAKE-RUNBOOK.md` (the process). Then:
- `tentative-outline.md` — paste the incoming outline here.
- `GUARDS-register.md` — the ratified premises the new outline is checked against.
- `reconciliation-worksheet.md` — the per-artifact + GUARD disposition worksheet.
- `retired/` — where superseded artifacts are archived (created on first retirement; nothing deleted).

**Trigger (fresh session):** `/and-reoutline`, or "intake this outline / rework the planning around
this / adapt-or-remove the existing planning."

**Not this:** a single messy chapter note → `design/run-02/idea-inbox.md` (the small-grain loop).

**What it produces:** the next `design/run-NN/` working layer (the adopted, tokenized outline +
carried-over instruments), thread-checked PASS, with a convergence-ledger digest. The frozen
`convergence/` baseline is never edited; retired run-02 artifacts are archived with tombstones.
