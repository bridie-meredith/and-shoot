# and-experiment

An **experiment workspace** for the bones-first pipeline — scaffolded by hand using
`/and-project` as the structural model, then seeded from `and-experiment/design/run-01/`.
It is **not** `active-project/` (which is live, b01 shipped through c16) and must never
be confused with it.

**Project:** a cultivation-reincarnation comedy in pre-Dance Westeros — a dragonless,
setting-blind Targaryen princess who grinds sacred dragons into immortality reagents and
accidentally builds a trade empire, until the Dance takes everything. Full bible:
`and-experiment/design/run-01/{idea-board,constraints,treatment,book-outlines}.md`.

**Why it exists:** to prove the bones-first inversion — narrate/derive bones, then
reverse-build the apparatus (cards, bible, memory, substance) and run the existing
facets/stitch packages on them. See `and-experiment/design/README.md`.

## Layout (mirrors active-project/)
- `staff/showrunner/memory.md` — seeded project state (bones-first mode).
- `audience/` — bound trio: youjo-senki-reader, danmachi-reader, literary-snob.
- `convergence/` — the outline convergence loop (round-by-round + cumulative ledger).
  Process spec: `and-experiment/design/convergence-process.md`.
- `actors/ warehouse/ theater/ draft/` — standard project dirs, populated as we build.
