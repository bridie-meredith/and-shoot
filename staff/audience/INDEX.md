# Audience Persona Library

18 personas available. 3 are selected per project at activation and placed in `active-project/audience/`.

Default starting cast: `cape-fic-reader`, `literary-snob`, `pulp-enthusiast` — covers character-stakes, voice/register, and plot momentum axes.

## Full personas (ready to use)

| Slug | Axis | Notes |
|------|------|-------|
| cape-fic-reader | character-stakes, rule consistency | lore-tracking, asymmetry-hungry |
| dark-fantasy-reader | grimdark, earned consequence, world weight | patient with bleakness when honest |
| literary-snob | voice, theme, meaning | patience-required, meaning-focused |
| pulp-enthusiast | plot momentum, escalation | impatient, pacing-obsessed |
| worm-canon-pedant | Worm-specific canon accuracy, power mechanics | Worm projects only |
